# JPApexPredators

An iOS app that lists and shows details about Jurassic Park’s apex predators.  
Built with Swift 6 and SwiftUI.

## What it does
- Loads predator data from a local JSON file.
- Displays predators in a searchable, filterable list (by type: land, sea, air).
- Toggle between alphabetical and movie order.
- Detail screen with image, movies, and key movie scenes.
- Interactive map showing predator current locations.
- Supports iMessage sticker pack with dinosaur images.

## Tech used
- Swift 6 / SwiftUI
- JSON decoding with `Codable`
- MapKit (annotations, camera positions, map styles)
- Reusable SwiftUI components
- Dark mode support
